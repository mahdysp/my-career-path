# تصاویر بخش نمایشگر

فایل‌های تصویر یا ویدیوی خود را در همین پوشه بریزید، بعد آرایه‌ی `SLIDES`
را در `app/components/ScreenShowcase.tsx` ویرایش کنید.

## مثال

```ts
const SLIDES: Slide[] = [
  {
    src: "/showcase/result.png",
    alt: "نتیجه‌ی آزمون",
    eyebrow: "نتیجه‌ی آزمون",
    title: "تصویری که از خودتان نداشتید",
    body: "...",
    label: "karex.ir/result",
  },
];
```

## ویدیو

```ts
{ src: "/showcase/demo.mp4", video: true, alt: "...", ... }
```

## ابعاد

نسبت قاب **۱۶:۱۰** است. اندازه‌ی پیشنهادی: **۱۶۰۰×۱۰۰۰ پیکسل**.
فرمت `webp` یا `avif` برای حجم کمتر بهتر است — کاربران ایرانی روی
اینترنت کند.

تا وقتی `src` خالی باشد، یک جای‌گیر گرادیانی با نام اسلاید نمایش داده
می‌شود، پس صفحه هیچ‌وقت خراب دیده نمی‌شود.
